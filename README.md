# Python Hanuman Art 🚩💻

Automated digital art generator using Python and OpenCV. The program detects edge contours, traces clean borders, and fills colors part-by-part using K-Means clustering with an active live cursor simulation.



---

## ✨ Features

- **Sequential Part Drawing:** Traces outer borders and fills color region-by-region (mukut, face, clothes, details).
- **Dynamic Cursor:** Real-time pointer tip simulating hand-drawn digital art.
- **Auto Screen Fit:** Proportional scaling to ensure full view without window cropping.
- **Pure Python & OpenCV:** No heavy frameworks, clean logic using Canny edges and K-Means segmentation.
